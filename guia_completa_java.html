1. Keyword super — Herencia

super es una referencia a la clase padre. Se usa en dos situaciones:

super() — Llamar al constructor del padre

public class Usuario {
    protected String nombre;

    public Usuario(String nombre) {
        this.nombre = nombre;
    }

    public void mostrarInfo() {
        System.out.println("Usuario: " + nombre);
    }
}

public class Admin extends Usuario {
    private String departamento;

    public Admin(String nombre, String departamento) {
        super(nombre);              // llama al constructor de Usuario
        this.departamento = departamento;
    }

    @Override
    public void mostrarInfo() {
        super.mostrarInfo();        // llama al método del padre
        System.out.println("Departamento: " + departamento);
        System.out.println("Rol: Administrador");
    }
}

// Uso
Admin admin = new Admin("Carlos", "TI");
admin.mostrarInfo();

Regla rápida

UsoPara qué sirve
super()Llamar al constructor del padre para inicializar sus atributos
super.metodo()Ejecutar el método del padre dentro del método sobreescrito

2. Collections

ArrayList — Lista ordenada, permite duplicados

import java.util.ArrayList;

ArrayList<String> lista = new ArrayList<>();
lista.add("Ana");
lista.add("Luis");
lista.add("Ana");        // permite duplicados

lista.get(0);            // "Ana" — acceso por índice
lista.remove("Luis");
lista.size();            // 2
lista.contains("Ana");   // true

// Recorrer
for (String nombre : lista) {
    System.out.println(nombre);
}

HashMap — Pares clave → valor

import java.util.HashMap;

HashMap<String, Integer> edades = new HashMap<>();
edades.put("Ana", 25);
edades.put("Luis", 30);

edades.get("Ana");           // 25 — acceso por clave
edades.containsKey("Luis");  // true
edades.remove("Luis");

// Recorrer
for (String clave : edades.keySet()) {
    System.out.println(clave + ": " + edades.get(clave));
}

HashSet — Sin duplicados, sin orden

import java.util.HashSet;

HashSet<String> set = new HashSet<>();
set.add("rojo");
set.add("azul");
set.add("rojo");      // ignorado, ya existe

set.size();           // 2
set.contains("azul"); // true

Cuándo usar cada uno

Necesitas...Usa
Lista con índicesArrayList
Clave → valorHashMap
Sin repetidosHashSet

Caso práctico — Gestión de una clase

import java.util.ArrayList;
import java.util.HashMap;

public class Clase {
    public static void main(String[] args) {

        HashMap<String, Integer> alumnos = new HashMap<>();
        alumnos.put("Ana", 8);
        alumnos.put("Luis", 4);
        alumnos.put("Marta", 6);
        alumnos.put("Carlos", 3);

        // Mostrar todos
        for (String nombre : alumnos.keySet()) {
            System.out.println(nombre + ": " + alumnos.get(nombre));
        }

        // Buscar nota de un alumno
        System.out.println("Nota de Ana: " + alumnos.get("Ana"));

        // Lista de aprobados
        ArrayList<String> aprobados = new ArrayList<>();
        for (String nombre : alumnos.keySet()) {
            if (alumnos.get(nombre) >= 5) {
                aprobados.add(nombre);
            }
        }

        for (String nombre : aprobados) {
            System.out.println("Aprobado: " + nombre);
        }
    }
}

3. Hibernate — Mapeo de entidades

Anotaciones esenciales

import jakarta.persistence.*;

@Entity                          // esta clase ES una tabla
@Table(name = "usuarios")        // nombre de la tabla (opcional)
public class Usuario {

    @Id                          // clave primaria
    @GeneratedValue(strategy = GenerationType.IDENTITY)  // autoincremento
    private Long id;

    @Column(name = "nombre", nullable = false, length = 100)
    private String nombre;

    @Column(name = "email", unique = true)
    private String email;

    // getters y setters obligatorios
}

Relaciones entre entidades

@Entity
public class Usuario {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @OneToMany(mappedBy = "usuario")
    private List<Pedido> pedidos;
}

@Entity
public class Pedido {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne
    @JoinColumn(name = "usuario_id")   // columna de clave foránea
    private Usuario usuario;
}

Tipos de relación

AnotaciónEjemplo
@OneToOneUn usuario → un perfil
@OneToManyUn usuario → muchos pedidos
@ManyToOneMuchos pedidos → un usuario
@ManyToManyMuchos alumnos → muchos cursos

5. Hibernate + DAO — Conceptos de examen

EntityManager — el objeto central

EntityManagerFactory emf = Persistence.createEntityManagerFactory("miUnidad");
EntityManager em = emf.createEntityManager();
MétodoQué hace
em.persist(obj)INSERT — guarda nuevo
em.find(Clase.class, id)SELECT por id
em.merge(obj)UPDATE — actualiza
em.remove(obj)DELETE

Transacciones — obligatorias para escribir

em.getTransaction().begin();
em.persist(usuario);
em.getTransaction().commit();  // si falla → rollback()

Patrón DAO

public class UsuarioDAO {
    private EntityManager em;

    public UsuarioDAO(EntityManager em) {
        this.em = em;
    }

    public void guardar(Usuario u) {
        em.getTransaction().begin();
        em.persist(u);
        em.getTransaction().commit();
    }

    public Usuario buscarPorId(Long id) {
        return em.find(Usuario.class, id);
    }

    public void eliminar(Long id) {
        Usuario u = buscarPorId(id);
        em.getTransaction().begin();
        em.remove(u);
        em.getTransaction().commit();
    }
}

Estados de una entidad

EstadoSignifica
TransientObjeto creado pero Hibernate no lo conoce
ManagedHibernate lo controla, cambios se sincronizan
DetachedExistió en BD pero ya no está en sesión activa
RemovedMarcado para borrar

6. Scanner — Terminal y archivos

Leer por terminal

import java.util.Scanner;

Scanner sc = new Scanner(System.in);  // System.in = teclado

System.out.print("Escribe tu nombre: ");
String nombre = sc.nextLine();   // lee texto completo

System.out.print("Escribe tu edad: ");
int edad = sc.nextInt();         // lee número entero

System.out.println("Hola " + nombre + ", tienes " + edad + " años");

sc.close();

Métodos según tipo de dato

MétodoLee
sc.nextLine()Texto completo (con espacios)
sc.next()Una sola palabra
sc.nextInt()Número entero
sc.nextDouble()Número decimal
sc.nextBoolean()true / false

Trampa frecuente: nextInt + nextLine

Problema: nextInt() deja un ENTER pendiente. El siguiente nextLine() se lo come y no espera al usuario. 
// MAL
int edad = sc.nextInt();
String nombre = sc.nextLine();  // se come el ENTER

// BIEN
int edad = sc.nextInt();
sc.nextLine();                  // limpia el ENTER pendiente
String nombre = sc.nextLine();  // ahora sí funciona

Leer un archivo

import java.util.Scanner;
import java.io.File;
import java.io.FileNotFoundException;

public class LeerArchivo {
    public static void main(String[] args) {
        try {
            File archivo = new File("datos.txt");
            Scanner sc = new Scanner(archivo);

            while (sc.hasNextLine()) {
                String linea = sc.nextLine();
                System.out.println(linea);
            }

            sc.close();

        } catch (FileNotFoundException e) {
            System.out.println("Archivo no encontrado");
        }
    }
}

Diferencia: Terminal vs Archivo

TerminalArchivo
Fuentenew Scanner(System.in)new Scanner(new File("ruta"))
Necesita try/catchNoSí (FileNotFoundException)
Cuándo acabaCuando el usuario paraCuando no hay más líneas
