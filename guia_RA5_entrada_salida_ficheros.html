Modelo 1 — Biblioteca Digital

Enunciado (8 puntos)

Contexto: Lectura de fichero CSV con libros disponibles.

Tarea: Explica qué hace el código, detecta 2 problemas importantes y reescríbelo de manera más segura.

Código Problemático

MAL 
public static void mostrarLibros(String nomFichero) {
    try {
        BufferedReader br =
            new BufferedReader(new FileReader(nomFichero));
        String linea = br.readLine();
        while (linea != null) {
            String[] campos = linea.split(";");
            if (campos[2].equals("DISPONIBLE")) {
                System.out.println(campos[0] + " - " + campos[1]);
            }
            linea = br.readLine();
        }
    } catch (Exception e) {
        System.out.println("Error");
    }
}

Problemas Detectados

Problema 1: Fuga de recursos

  • El BufferedReader nunca se cierra
  • Cuando el método termina, el fichero queda abierto
  • Solución: usar try-with-resources o br.close()

Problema 2: Captura genérica de Exception

  • catch (Exception e) captura TODO — mala práctica
  • No sabemos qué error ocurrió (fichero no existe, formato incorrecto…)
  • Solución: capturar excepciones específicas

Problema 3 (BONUS): Sin validación de índices

  • Si una línea no tiene 3 campos, campos[2] causa ArrayIndexOutOfBoundsException
  • No hay comprobación de campos.length

Código Corregido

BIEN 
public static void mostrarLibros(String nomFichero)
        throws FileNotFoundException, IOException {

    try (BufferedReader br =
            new BufferedReader(new FileReader(nomFichero))) {

        String linea;
        while ((linea = br.readLine()) != null) {
            linea = linea.trim();
            if (linea.isEmpty()) continue;

            try {
                String[] campos = linea.split(";");

                if (campos.length < 3) {
                    System.err.println("Línea malformada: " + linea);
                    continue;
                }

                if (campos[2].trim().equals("DISPONIBLE")) {
                    System.out.println(campos[0].trim() + " - " + campos[1].trim());
                }

            } catch (ArrayIndexOutOfBoundsException e) {
                System.err.println("Formato incorrecto");
            }
        }

    } catch (FileNotFoundException e) {
        System.err.println("ERROR: Fichero no encontrado");
    } catch (IOException e) {
        System.err.println("ERROR I/O: " + e.getMessage());
    }
}

Cambios Clave

AspectoAntesDespués
Cierrebr.close() manual (nunca ejecutado)try-with-resources
Excepcionescatch(Exception)Específicas
ValidaciónSin comprobar lengthlength check
EspaciosSin limpiartrim()

Pregunta Teórica (2 puntos)

¿Por qué capturar directamente Exception es mala práctica?

Capturar Exception genérica oculta los problemas reales:

  1. Falta de información: no sabes qué falló — ¿no existe el fichero? ¿formato incorrecto?
  2. Recuperación imposible: sin saber el error, no puedes reaccionar adecuadamente
  3. Enmascara bugs: puede capturar NullPointerException, ArithmeticException… errores que deberían fallar visiblemente
Manera Correcta 
try {
    // código I/O
} catch (FileNotFoundException e) {
    // Fichero no existe: actuar diferente
} catch (IOException e) {
    // Error I/O: reintentar, logs, etc.
} catch (NumberFormatException e) {
    // Datos inválidos: saltarse línea
}

Modelo 2 — Plataforma Streaming

Enunciado (8 puntos)

Este método pide una puntuación entre 0 y 10 y la muestra con un decimal.

Tarea: Detecta los dos errores y corrígelos.

Código con Errores

MAL 
public static float pedirPuntuacion(Scanner sc) {
    System.out.print("Puntuación: ");
    float puntuacion = sc.nextFloat();

    if (puntuacion < 0 && puntuacion > 10) {    // ERROR 1
        throw new IllegalArgumentException("Puntuación incorrecta");
    }

    System.out.printf("Has introducido: %d puntos", puntuacion);  // ERROR 2
    return puntuacion;
}

Errores Detectados

Error 1: Lógica de validación incorrecta

El problema está en: if (puntuacion < 0 && puntuacion > 10)

¿Por qué falla? Es imposible que un número sea menor que 0 Y mayor que 10 al mismo tiempo. La validación nunca se ejecuta.

Solución: usar || (OR) 
if (puntuacion < 0 || puntuacion > 10)

Error 2: Especificador de formato incorrecto

El problema está en: System.out.printf("Has introducido: %d puntos", puntuacion)

¿Por qué falla? %d es para enteros (int). puntuacion es float (decimales).

Solución: usar %.1f 
System.out.printf("Has introducido: %.1f puntos\n", puntuacion);

Código Corregido

BIEN 
public static float pedirPuntuacion(Scanner sc) {
    System.out.print("Puntuación: ");
    float puntuacion = sc.nextFloat();

    // ERROR 1 CORREGIDO: && por ||
    if (puntuacion < 0 || puntuacion > 10) {
        throw new IllegalArgumentException("Puntuación incorrecta");
    }

    // ERROR 2 CORREGIDO: %d por %.1f
    System.out.printf("Has introducido: %.1f puntos\n", puntuacion);
    return puntuacion;
}

Pregunta Teórica (2 puntos)

¿Cuál es la diferencia entre %d, %f y %.1f en printf?

EspecificadorTipoEjemploResultado
%dentero (int)%d con 55
%ffloat (6 decimales por defecto)%f con 5.75.700000
%.1ffloat (1 decimal exacto)%.1f con 5.75.7
%.2ffloat (2 decimales)%.2f con 5.75.70

Ejemplos

double num = 19.567;
System.out.printf("%d",   num);   // Error — %d es para enteros
System.out.printf("%f",   num);   // 19.567000
System.out.printf("%.2f", num);   // 19.57
System.out.printf("%.1f", num);   // 19.6
System.out.printf("%.0f", num);   // 20 (redondea)

Modelo 3 — Gestión Hotel

Enunciado (8 puntos)

Escribe el método guardarReserva() que añada una línea al fichero.

Requisitos: Formato cliente;habitacion · NO sobrescribir reservas anteriores (modo append) · Manejar IOException correctamente.

Solución 1: FileWriter (Básica)

import java.io.FileWriter;
import java.io.IOException;

public static void guardarReserva(
        String nomFichero, String cliente, int habitacion)
        throws IOException {

    try (FileWriter fw = new FileWriter(nomFichero, true)) {
        // true = modo append (añadir, no sobrescribir)
        fw.write(cliente + ";" + habitacion + "\n");
    } catch (IOException e) {
        System.err.println("Error: " + e.getMessage());
        throw e;
    }
}

Solución 2: BufferedWriter (Recomendada)

RECOMENDADA 
import java.io.*;

public static void guardarReserva(
        String nomFichero, String cliente, int habitacion)
        throws IOException {

    try (BufferedWriter bw = new BufferedWriter(
            new FileWriter(nomFichero, true))) {
        bw.write(cliente + ";" + habitacion);
        bw.newLine();   // más legible que "\n"
    } catch (IOException e) {
        System.err.println("Error: " + e.getMessage());
        throw e;
    }
}

Solución 3: Files (Moderna — Java 7+)

import java.nio.file.*;

public static void guardarReserva(
        String nomFichero, String cliente, int habitacion)
        throws IOException {

    String linea = cliente + ";" + habitacion + "\n";
    Files.write(
        Paths.get(nomFichero),
        linea.getBytes(),
        StandardOpenOption.APPEND,
        StandardOpenOption.CREATE
    );
}

Uso (igual en las 3 soluciones)

try {
    guardarReserva("reservas.txt", "Juan García",  101);
    guardarReserva("reservas.txt", "María López",  205);
    guardarReserva("reservas.txt", "Carlos Ruiz",  108);
} catch (IOException e) {
    System.out.println("Fallo al guardar");
}

Fichero resultante (reservas.txt):

Juan García;101
María López;205
Carlos Ruiz;108

Punto Clave: Append vs Sobrescribir

SOBRESCRIBE — peligro de pérdida de datos 
new FileWriter(nomFichero)        // false implícito
new FileWriter(nomFichero, false) // sobrescribe

FileWriter fw1 = new FileWriter("datos.txt");
fw1.write("Día 1");
fw1.close();
// Después:
FileWriter fw2 = new FileWriter("datos.txt");
fw2.write("Día 2");
fw2.close();
// Resultado: solo "Día 2" — perdió Día 1
APPEND — mantiene datos 
new FileWriter(nomFichero, true)  // append

FileWriter fw1 = new FileWriter("datos.txt", true);
fw1.write("Día 1\n");
fw1.close();
// Después:
FileWriter fw2 = new FileWriter("datos.txt", true);
fw2.write("Día 2\n");
fw2.close();
// Resultado: "Día 1\nDía 2"

Lees un fichero CSV con ventas: nombreVideojuego;precio

Solución Simple

double total = 0;
try (BufferedReader br =
        new BufferedReader(new FileReader("ventas.txt"))) {
    String linea;
    while ((linea = br.readLine()) != null) {
        String[] partes = linea.split(";");
        String nombre  = partes[0];
        double precio  = Double.parseDouble(partes[1]);

        total += precio;                                          // acumular
        System.out.printf("%s: %.2f€\n", nombre, precio);        // mostrar
    }
    System.out.printf("\nTotal: %.2f euros\n", total);
} catch (IOException e) {
    System.out.println("Error lectura");
} catch (NumberFormatException e) {
    System.out.println("Precio inválido");
}

Solución Robusta (Recomendada)

RECOMENDADA 
double total = 0;
int lineasOK = 0, lineasError = 0;

try (BufferedReader br =
        new BufferedReader(new FileReader("ventas.txt"))) {
    String linea;
    int numLinea = 0;

    while ((linea = br.readLine()) != null) {
        numLinea++;
        linea = linea.trim();
        if (linea.isEmpty()) continue;

        try {
            String[] partes = linea.split(";");

            if (partes.length < 2) {
                System.err.println("Línea " + numLinea + ": faltan campos");
                lineasError++;
                continue;
            }

            String nombre = partes[0].trim();
            double precio = Double.parseDouble(partes[1].trim());

            if (precio < 0) {
                System.err.println("Línea " + numLinea + ": precio negativo");
                lineasError++;
                continue;
            }

            total += precio;
            lineasOK++;
            System.out.printf("%s: %.2f€\n", nombre, precio);

        } catch (NumberFormatException e) {
            System.err.println("Línea " + numLinea + ": precio no válido");
            lineasError++;
        }
    }

    System.out.printf("\n=== RESUMEN ===\n");
    System.out.printf("Válidas: %d\n",  lineasOK);
    System.out.printf("Errores: %d\n",  lineasError);
    System.out.printf("Total:   %.2f€\n", total);

} catch (FileNotFoundException e) {
    System.err.println("ERROR: Fichero no encontrado");
} catch (IOException e) {
    System.err.println("ERROR I/O: " + e.getMessage());
}

Pregunta Teórica (2 puntos)

¿Por qué Double.parseDouble() genera excepciones con datos mal formateados?

Double.parseDouble() lanza NumberFormatException cuando el String no puede convertirse a número válido.

ValorProblema
"Gratis"No es número
"19,99"Coma en lugar de punto
"19 euros"Contiene texto extra

Cómo manejarlo

}

6. Conceptos Clave RA5

1. try-with-resources (Java 7+)

Cierra automáticamente el recurso al salir del bloque:

VIEJO — cierre manual 
BufferedReader br = null;
try {
    br = new BufferedReader(new FileReader("archivo.txt"));
    // código
} finally {
    if (br != null) br.close();
}
MODERNO — cierre automático 
try (BufferedReader br = new BufferedReader(new FileReader("archivo.txt"))) {
    // código
}   // se cierra automáticamente aquí

2. Lectura línea a línea

String linea;
while ((linea = br.readLine()) != null) {
    // readLine() retorna String o null (EOF)
    // null = fin de fichero
}

3. Parsing CSV

String linea = "Elden Ring;59.99";
String[] campos = linea.split(";");
// campos[0] = "Elden Ring"
// campos[1] = "59.99"

4. Excepciones en E/S

try {
    // operación I/O
} catch (FileNotFoundException e) {
    // fichero no existe
} catch (NumberFormatException e) {
    // número inválido
} catch (IOException e) {
    // error I/O genérico — siempre al final
}

8. Errores Comunes a Evitar

Error 1: No manejar NumberFormatException

MAL 
double precio = Double.parseDouble(partes[1]);
BIEN 
try {
    double precio = Double.parseDouble(partes[1].trim());
} catch (NumberFormatException e) {
    System.err.println("Precio inválido");
    continue;
}

Error 2: No validar índices del array

MAL — puede fallar si falta campo 
String nombre = partes[0];
double precio = Double.parseDouble(partes[1]);
BIEN 
if (partes.length < 2) {
    System.err.println("Formato incorrecto");
    continue;
}

Error 3: No usar trim()

MAL — espacios causan error 
double precio = Double.parseDouble(partes[1]);
BIEN 
double precio = Double.parseDouble(partes[1].trim());

Error 4: No cerrar fichero

MAL 
BufferedReader br = new BufferedReader(new FileReader("archivo.txt"));
String linea = br.readLine();   // br no se cierra
BIEN 
try (BufferedReader br = new BufferedReader(new FileReader("archivo.txt"))) {
    String linea = br.readLine();   // se cierra automáticamente
}

Error 5: Lógica de validación incorrecta

MAL — nunca se cumple simultáneamente 
if (valor < 0 && valor > 10)   // imposible
BIEN 
if (valor < 0 || valor > 10)   // correcto
